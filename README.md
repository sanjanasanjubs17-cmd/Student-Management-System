
# Student Management System

A beginner-friendly web application for managing student records.

## Features

- Add student records
- View student details in a table
- Edit and update student records
- Delete student records
- Search by name, roll number, or email
- Save records using browser Local Storage
- Display total student count
- Prevent duplicate roll numbers
- Show success messages after adding or updating records

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Add and manage student records.
